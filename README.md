# Espaço Foxxy – Projeto completo atualizado

## Abrir no VS Code
1. Extraia o ZIP.
2. Abra o VS Code > Arquivo > Abrir Pasta > `espaco-foxxy-projeto-final`.
3. Abra `index.html` e selecione **Open with Live Server** (ou Go Live).
4. Clique nas categorias de tratamentos: elas agora abrem **na mesma aba**.
5. Os botões de avaliação gratuita enviam a cliente para o WhatsApp (21) 97008-7151, com mensagem preparada para a Dra. Elizabete.
